# baton：会话接力

接力开始后，用户的每条消息由 baton 的钩子原样转给后台 Agent，你只负责把它的回复贴出来。脚本在本 skill 目录往上两级的 `scripts/baton.py`（下文写作 `BATON`）。

## 开始

1. 先确认这件活后台 Agent 做得了。做不了的三类：要看截图或图片；要用只有当前会话才有的工具（MCP、页面发布、提问弹窗）；要读 Claude 的会话记录。属于这三类的，告诉用户，不开始接力。
2. 定权限：只改文件的活用 `low`；要装依赖、构建、跑会写文件的脚本、git 提交的，先问用户要不要开 `medium`。
3. 后台运行（第一轮可能要几分钟）：
   ```bash
   python3 BATON start --from-history [--auto medium]
   ```
   脚本自己取用户最近一条请求的原话。你不写开场内容、不补背景、不改措辞。完成后把输出原样贴给用户。

## 之后每一轮

钩子已经把用户原话转给后台 Agent，回复在本轮上下文的【baton 接力回复】里。只把 BEGIN 和 END 之间的内容原样贴出：不改写、不删减、不总结、不加评论、不调用工具、不运行 `BATON`。

## 其他

- 用户以 `//` 开头的消息是对你说的，钩子不转发，正常回答。
- 改权限：`python3 BATON auto medium`（或 `low`），下一轮生效。看状态：`python3 BATON status`。
- 用户发结束词（默认「结束接力」「end relay」）时钩子会结束接力，你用一句话确认。
- 整个接力在当前对话里进行，不开新会话，不派子 Agent。
- 回复里出现「警告：后台 Agent 改了受保护目录里的文件」，原样贴出并提醒用户核对。
